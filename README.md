# Course Registration Form

A responsive course registration form built with HTML5, CSS3 and JavaScript, with no external frameworks or libraries. Students enter their name, email, mobile number, password, course and attendance mode, and receive a unique registration ID once everything is valid.

## Features
- HTML5 validation plus JavaScript checks with field-specific error messages
- Live password checklist, strength indicator and show/hide option
- Email typo suggestions and automatic focus on the first invalid field
- Responsive layout, light and dark mode, and keyboard accessibility

## Technologies
HTML5, CSS3, JavaScript

## Future enhancements
Database integration, email verification and course seat-availability checking
